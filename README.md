# Cars Dealership

Repository: xrwvm-fullstack-developer-capstone

Project name: **Cars Dealership**

A full-stack web application for a national car retailer. Users can browse
dealerships, filter them by state, read dealer reviews, register, log in and
post their own reviews. The backend is built with Django and a Node.js/Express
microservice (MongoDB), the frontend with React, and the app is deployed with
Docker, Kubernetes and IBM Cloud Code Engine. Reviews are analysed with a
sentiment-analysis microservice, and CI runs through GitHub Actions.
